# 🛍️ Catálogo digital

Proyecto de catálogo online para que los clientes exploren productos y envíen pedidos a un negocio.

## Cliente
- Entrar al catálogo y ver categorías.
- Buscar productos y ver fotos, nombre, descripción y precio.
- Elegir producto y cantidad.
- Agregar productos al pedido, ver el total y tocar **Hacer pedido**.
- Enviar el pedido al negocio.

## Dueño
- Agregar productos y categorías.
- Editar precios, fotos y descripciones.
- Activar o desactivar productos.
- Ver los pedidos recibidos.

**Presupuesto de referencia:** $20.000 aprox.
